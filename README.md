# ESPE Desarrollo de Videojuegos

Repositorio de proyectos, prototipos y actividades de la asignatura **36869-DESARROLLO DE VIDEOJUEGOS** de la Universidad de las Fuerzas Armadas ESPE.

**Docente:** Hector Paul Pinto Pachacama.

## Primer parcial

La carpeta `1P/` contiene la conceptualización y el prototipo de **La Última Mesa**, un juego de blackjack inspirado en Balatro.

Consultar [la documentación del primer parcial](1P/README.md) para ejecutar el prototipo y sus pruebas.
